#### 4.0.3 画面要素

| 要素ID | 要素名 | 種類 | 必須 | 説明 |
|--------|--------|------|------|------|
| AUTH-001 | タイトル | テキスト | ○ | 「ほんだし AI アシスタント」 |
| AUTH-002 | 説明文 | テキスト | ○ | 「このサービスは現在限定公開中です」 |
| AUTH-003 | パスワード入力 | input[type=password] | ○ | パスワード入力フィールド |
| AUTH-004 | アクセスボタン | button | ○ | 認証実行ボタン |
| AUTH-005 | エラーメッセージ | テキスト | - | 認証失敗時に表示 |
| AUTH-006 | 残り試行回数 | テキスト | - | 「（残り○回）」 |

#### 4.0.4 画面動作仕様

| アクション | トリガー | 処理内容 | 結果 |
|-----------|---------|---------|------|
| パスワード検証 | アクセスボタンクリック or Enter | API呼び出し `POST /api/v1/auth/verify` | 成功: ウェルカム画面へ / 失敗: エラー表示 |
| 認証成功 | API成功レスポンス | sessionStorageにトークン保存 | SCR-002（ウェルカム画面）へ遷移 |
| 認証失敗 | API失敗レスポンス | エラーメッセージ表示、残り回数更新 | 画面に留まる |
| ロックアウト | 5回連続失敗 | 入力フィールド無効化 | 「1分後に再試行してください」表示 |
| 認証済みチェック | ページロード時 | sessionStorageのトークン確認 | 有効: SCR-002へ / 無効: 入力画面表示 |

#### 4.0.5 バリデーションルール

| フィールド | ルール | エラーメッセージ |
|-----------|--------|----------------|
| パスワード | 必須 | 「パスワードを入力してください」 |
| パスワード | 1文字以上 | 「パスワードを入力してください」 |

#### 4.0.6 状態管理

```typescript
interface AuthState {
  isAuthenticated: boolean;      // 認証済みフラグ
  remainingAttempts: number;     // 残り試行回数（初期値: 5）
  isLocked: boolean;             // ロックアウト状態
  lockUntil: number | null;      // ロック解除時刻（Unix timestamp）
  errorMessage: string | null;   // エラーメッセージ
}

// sessionStorageキー
const AUTH_TOKEN_KEY = 'mvp_auth_token';
const AUTH_TIMESTAMP_KEY = 'mvp_auth_timestamp';
```

#### 4.0.7 セキュリティ考慮事項

| 項目 | 対策 |
|------|------|
| ブルートフォース | 5回失敗で1分間ロックアウト |
| パスワード漏洩 | 入力フィールドはtype="password"でマスク |
| セッション管理 | sessionStorage使用（タブ閉じで無効化） |
| 通信 | HTTPS必須、パスワードはPOSTボディで送信 |

> **注記**: これはMVP期間の簡易的なアクセス制限です。本格的な認証基盤（Azure AD B2C等）はPhase 3で実装予定です。

### 7.2 フォーカス管理

| 画面/操作 | フォーカス挙動 |

### 7.3 キーボード操作

| キー | 動作 |
|------|------|
| Tab | 次のインタラクティブ要素へ移動 |

| Enter | ボタン押下/メッセージ送信 |
| Escape | モーダルを閉じる |
| 矢印キー（上下） | クイックリプライ間を移動 |
| Space | チェックボックス/アコーディオン開閉 |

### 7.4 ローディング・エラー時のUX

| 状態 | UI表現 | 操作 |
|------|--------|------|

| AI応答待ち | タイピングインジケータ（3点ドット） | キャンセル不可 |

| タイムアウト（60秒） | エラーメッセージ＋「再試行」ボタン | 再試行可能 |
| API失敗 | インラインエラー＋「再試行」ボタン | 再試行可能 |
| セッション期限切れ | ダイアログ表示＋「ページを再読み込み」 | 自動リロード選択可 |
| ネットワークオフライン | トースト通知「オフラインです」＋入力無効化 | 接続回復で自動復帰 |

### 7.4a セッションタイムアウト通知

| 経過時間 | 通知方法 | 内容 |
|---------|---------|------|
| 25分経過 | トースト通知（5秒表示） | 「あと5分で自動的にセッションが終了します」 |
| 28分経過 | モーダルダイアログ | 「セッションがまもなく終了します。続けますか？」＋「続ける」ボタン |
| 30分経過 | モーダルダイアログ | 「セッションが終了しました」＋「新しい会話を始める」ボタン |

**ダイアログ仕様**

```
┌─────────────────────────────────────────────┐
│  ⚠️ セッションがまもなく終了します            │
│                                             │
│  あと2分で無操作によりセッションが終了します。│
│  続ける場合は下のボタンを押してください。     │
│                                             │
│         ┌────────────────┐                 │
│         │    続ける      │ ← プライマリボタン │
│         └────────────────┘                 │
└─────────────────────────────────────────────┘
```

**「続ける」押下時の動作**
- セッションタイムアウトをリセット（30分延長）
- ダイアログを閉じ、入力フィールドにフォーカス

### 7.5 メッセージ自動スクロール

| 条件 | 挙動 |
|------|------|
| 新規メッセージ受信時 | 最下部までスムーズスクロール |
| ユーザーが上にスクロール中 | 自動スクロールしない（「新着メッセージ」ボタン表示） |
| 「新着メッセージ」ボタン押下 | 最下部までスクロール |
