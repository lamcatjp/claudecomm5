# [Phase 1-7] API 統合テスト

## 概要
フロントエンドとバックエンドの統合テストを実施し、E2Eでの動作を確認する。

## テストシナリオ

### シナリオ1: 基本会話フロー
```
1. 新規会話作成 (POST /conversations)
2. メッセージ送信 (POST /chat/messages)
3. 応答確認（content, intent, suggestions）
4. フォローアップ質問
5. セッション終了
```

### シナリオ2: RAG検索フロー
```
1. レシピ質問「味噌汁の作り方を教えて」
2. RAG検索が実行される
3. レシピ情報を含む応答が返る
4. サジェスト「減塩にしたい」等が表示される
```

### シナリオ3: FAQ質問フロー
```
1. FAQ質問「ほんだしの保存方法は？」
2. FAQインデックスから検索
3. FAQ情報を含む応答が返る
```

### シナリオ4: SSEストリーミング
```
1. ストリーミングリクエスト
2. チャンクごとのデータ受信確認
3. 完了イベント確認
```

## テストツール
| ツール | 用途 |
|-------|------|
| pytest | バックエンド統合テスト |
| Jest | フロントエンドテスト |
| Playwright | E2Eテスト |
