## テスト種別

### 単体テスト
| 対象 | ツール | カバレッジ目標 |
|------|--------|--------------|
| API関数 | pytest | 80% |
| ユーティリティ | pytest | 80% |
| Reactコンポーネント | Jest | 80% |
| カスタムフック | Jest | 80% |

### 統合テスト
| 対象 | テスト内容 |
|------|-----------|
| Chat API | リクエスト→レスポンス全体フロー |
| RAG Pipeline | 検索→生成フロー |
| Session管理 | セッション作成→更新→取得 |

### E2Eテスト（Playwright）
| シナリオ | 説明 |
|---------|------|
| 1. 基本会話 | 質問→回答→フォローアップ |
| 2. レシピ検索 | レシピ質問→レシピカード表示 |
| 3. FAQ | FAQ質問→回答表示 |
| 4. クイックリプライ | サジェストクリック→送信 |

### LLM品質テスト
```
30サンプルの質問に対して以下を評価：
- 関連性（5段階評価）
- 正確性（正確/不正確）
- 有用性（5段階評価）
- トーン（適切/不適切）
```

## テスト実行コマンド
```bash
# バックエンド
cd api
pytest tests/ --cov=. --cov-report=html

# フロントエンド
cd apps/web
npm run test -- --coverage

# E2E
npx playwright test
```
